# mRefinerModel

[English](README.md) | **Русский**

mRefinerModel — небольшой **уточнитель границ фонем** для разметки пения. Работает после любого разметчика (WFL-ASR, SOFA,
HubertFA, MFA, черновая ручная разметка): для каждой границы между соседними фонемами смотрит на подробную
мел-спектрограмму вокруг неё (±120 мс, шаг 2,5 мс), знает фонемы с обеих сторон и их длительности, как их поставил
первый этап, и сдвигает границу туда, где она на самом деле. Фонемы, их порядок и минимальную длину не меняет;
граница сдвигается, только если уточнитель достаточно уверен.

- ~3,5 млн параметров, свёрточная сеть — намного быстрее первого этапа; работает и на процессоре (около 30× быстрее реального времени на 2 ядрах).
- Вход и выход: HTK `.lab` (`начало конец фонема`, единицы 100 нс) или список `(начало, конец, фонема)` в Python.
- Первая модель — для **русского пения** (см. [Модели](#модели)); можно обучить свою на своих данных.

## Результаты (русская модель)

Первый этап — русская модель WFL-ASR, на записях, которых модели не видели (от каждого голоса; среднее по голосам).
«С ограничением» — средняя ошибка, где одна граница даёт не больше 100 мс.

| | средняя ошибка | с ограничением | ≤ 20 мс | промахов > 50 мс |
|---|---|---|---|---|
| WFL-ASR, выравнивание по тексту | 13,2 мс | 10,3 мс | 88,4 % | 4,2 % |
| **+ mRefinerModel** | **11,5 мс** | **8,9 мс** | **90,2 %** | **3,1 %** |
| WFL-ASR, распознавание без текста | 17,7 мс | | 85,6 % | |
| **+ mRefinerModel** | **16,5 мс** | | **87,9 %** | |

Второй проход не помогает. Больше всего оставшейся ошибки — между паузами и вдохами (SP/AP) и между одинаковыми
гласными на двух нотах (а–а): в спектре там почти не за что зацепиться.

### Другие языки и стили разметки

Уточнитель учится тому, *где ставит границы разметчик его обучающих данных*. На разметке другого стиля (другой
датасет, другие правила) или с незнакомыми фонемами режим `normal` может сдвигать границы прочь от этого стиля.
Режим `safe` (включается сам, если большинство фонем незнакомы) двигает только уверенные границы и недалеко: в наших
проверках на открытом многоязычном наборе пения (русский, английский, японский и другие, все фонемы незнакомы
модели) он практически не ухудшал разметку — правильные границы сдвигались в среднем на 1–5 мс, сдвинутые
возвращались не хуже, а то и немного лучше. Но и выигрыша там почти нет. Для настоящего выигрыша на другом языке
или стиле обучите уточнитель на этих данных.

## Установка

```
pip install -r requirements.txt     # torch, torchaudio, numpy, soundfile, PyYAML
```

## Использование

```
python refine.py -i папка_с_wav_и_lab -m models/mrefinermodel-ru -o папка_для_результата
python refine.py -i ... -m ... -o ... --labs папка_с_lab            # разметка в другой папке
python refine.py -i ... -m ... -o ... --map их_в_наши.txt           # другие названия фонем: строки "их -> наша"
python refine.py -i ... -m ... -o ... --mode safe                  # другой язык / разметка другого стиля
```

```python
from mrefinermodel import Refiner
r = Refiner("models/mrefinermodel-ru")          # device="cpu" / "cuda"
segments = r.refine(audio, sr, segments)        # [(начало, конец, фонема), ...] в секундах
segments, info = r.refine(audio, sr, segments, mode="safe", return_info=True)
# info: {"mode": "safe", "unknown_share": 0.0, "boundaries": 120, "moved": 37}
```

Режимы: `auto` (по умолчанию: `safe`, если модели незнакомы больше половины фонем, иначе `normal`), `normal`,
`safe`. `min_confidence` и `max_shift_ms` переопределяют настройки режима.

Проверка по эталонной разметке:

```
python evaluate.py --ref эталон --pred первый_этап --refined после_уточнения
```

## Обучение своей модели

```
python train.py --train data/train --val data/val --run my_refiner
python train.py --train data/train --val data/val --pred-train pred/train --pred-val pred/val --run my_refiner
python export.py runs/my_refiner models/my-refiner --zip my-refiner.zip
```

`--train` / `--val`: `.wav` + эталонные `.lab`. Лучше с `--pred-train` / `--pred-val`: те же файлы, размеченные
вашим первым этапом, — тогда уточнитель учится его настоящим ошибкам. Разметка обучающих файлов должна быть сделана
моделью, которая их не видела (например, трижды обучить первый этап на 2/3 данных и каждый раз размечать
оставшуюся треть). Без неё уточнитель учится на случайных сдвигах эталона (`config/synthetic.yaml`). Имена файлов
`голос__что-угодно.wav` дают в журнале обучения среднее по голосам. Обучение — минуты на видеокарте.
